WHITE PACK QUOTATION APP — INSTALLATION

1. Upload quotation.html, manifest.webmanifest, icon-192.png, and icon-512.png together into the same folder in your GitHub Pages repository.
2. If your quotation page is already named quotation.html, replace it with this updated quotation.html.
3. Keep all four files in the same folder. Do not rename the icon or manifest files unless you also update quotation.html and manifest.webmanifest.
4. Open the published HTTPS quotation.html link in Chrome on Android. Tap ⋮ > Add to Home screen or Install app. The icon may take a little time to refresh if an older shortcut already exists; remove the old shortcut and add it again.

This package updates the quotation page only. It does not change admin.html, orders.html, or driver-tracking.html.
