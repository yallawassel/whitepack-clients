WHITE PACK — PUBLISH-FROM-PHONE CATALOGUE

CUSTOMER LINK:
After uploading this folder to GitHub Pages, the customer uses index.html.

PHONE ADMIN:
Open admin.html on your phone. Enter:
- GitHub username
- Repository name
- Branch (usually main)
- GitHub Personal Access Token with permission to edit repository contents

Then add photos/products and press Publish to Website.

IMPORTANT:
The GitHub token is saved in this browser's local storage. For security, use a token limited to this repository if your GitHub setup supports fine-grained tokens, and do not share the admin page/token with customers.

GITHUB PAGES:
Repository Settings -> Pages -> Deploy from branch -> main -> /(root).
Your customer URL will be:
https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/

This package uses GitHub as the image/file host and publishes products.json automatically from the phone.
